# Case Study

## Project Summary

Literary Writing Agent is a public portfolio project that demonstrates how an AI-assisted writing workflow can support original fiction development without cloning any author's style or using protected source text.

The project focuses on four writing moments:

- turning a loose premise into an outline
- expanding a character seed into usable creative prompts
- revising a scene for texture and subtext
- rewriting objectifying description into a stronger subject-centered point of view

## Design Goal

The goal is not to replace the writer. The Agent creates structured options, asks craft questions, and explains revision choices so the writer can decide what to keep, reject, or rewrite.

## Key Product Decisions

- Keep the Safe Demo deterministic and offline.
- Store writing ethics as configuration and documentation, not only as prose in the README.
- Include revision rationale so outputs remain inspectable.
- Use original fictional examples only.
- Treat female subjectivity as a craft requirement, not a decorative add-on.

## Portfolio Value

This project shows practical judgment across Agent workflow design, content safety, promptable writing frameworks, reproducible demo scripts, and repository hygiene.

## Non-Goals

- No commercial deployment claims.
- No private writing material.
- No style cloning.
- No use of protected excerpts.
- No real customer or partner references.
