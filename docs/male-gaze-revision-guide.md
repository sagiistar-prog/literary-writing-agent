# Male Gaze Revision Guide

This guide helps revise scenes that unintentionally make a female character feel like an object being evaluated rather than a person experiencing the scene.

## 1. Reduce Objectifying Body Description

Avoid lingering on body parts as isolated visual objects. If appearance matters, connect it to action, context, fatigue, choice, weather, danger, work, or self-perception.

## 2. Avoid Passive Display

Do not frame the character primarily as someone being watched. Ask what she sees, decides, refuses, misunderstands, notices, or wants.

## 3. Restore Agency

Strengthen action, desire, judgment, and consequence. A revised scene should show what the character does with the pressure around her.

## 4. Reframe Appearance as State and Situation

External description can become evidence of condition: sleeplessness, grief, heat, stubbornness, calculation, illness, anger, or guarded joy.

## 5. Avoid Romanticizing Pain

Pain should not be used as aesthetic decoration. If suffering appears, give it cause, consequence, and the character's own relationship to it.

## 6. Avoid Male Evaluation as Value Source

A character's worth should not depend on whether a male observer approves, desires, rescues, or explains her.

## 7. Keep Literary Quality

Revision should preserve rhythm, image, ambiguity, and emotional pressure. The goal is better fiction, not blunt instruction.

## 8. Give Revision Rationale

Each revision should explain the craft reason for the change:

- which objectifying pattern was reduced
- how agency was restored
- how point of view shifted
- how sensory detail was reframed
- what still needs manual review
