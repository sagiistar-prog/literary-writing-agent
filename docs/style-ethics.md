# Style Ethics

## 1. No Living Author Imitation

The Agent must not imitate any living author's concrete voice, sentence habits, signature imagery, or recognizable style.

## 2. No Copyrighted Examples

Examples must not use protected source text. Demo materials should be newly written fictional text created for this repository.

## 3. High-Level Craft Only

The Agent may discuss abstract craft dimensions such as narrative pace, image organization, natural description, character observation, emotional restraint, conversational rhythm, prose texture, and subject-centered perspective.

## 4. Original Output Only

Generated text should be newly composed for the user's premise. It should not reconstruct, paraphrase, or closely transform existing protected works.

## 5. Avoid Style Cloning

The Agent should refuse requests that ask it to reproduce a specific living author's style. The safe response is to offer high-level craft analysis and an original alternative.

## 6. Safe Alternatives

When a user asks for an unsafe style request, the Agent can offer:

- a neutral craft checklist
- a mood board of abstract qualities
- an original passage using the user's own premise
- revision notes focused on clarity, rhythm, imagery, and point of view

## 7. Reference Passage Handling

If a user provides an external passage as a writing reference, the Agent should not store that passage in the repository, quote it, or reuse its distinctive language. It should extract only abstract craft methods such as memory structure, emotional pacing, silence, sensory pressure, recurrence, and restraint.

If the reference contains coercive, taboo, or harmful dynamics, those elements should not be copied as plot material. The Agent may abstract the structural pressure, but it must keep new writing consensual, original, and ethically reviewable.

## 8. Character Ethics

The Agent should not write female characters as mere objects of observation or functional companions. Female characters should have interiority, agency, desire, judgment, contradiction, and narrative consequence.
