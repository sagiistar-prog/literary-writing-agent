# 0.3 验收记录

范围：本机写作提案和作者修订流程。日期：2026-09-18。

## 自动回归

本机已通过 27 项 Python 测试、插件与技能包装校验、公开仓库审计、四个兼容命令和四类示例一致性检查。1440 与390宽度浏览器报告见 [browser-review.json](evaluation/browser-review.json)，均无页面脚本错误、指定 axe 规则违规或横向溢出。

Python 测试覆盖无建议不编造、零采纳保真、只改选中范围、重复原句定位、删除与插入、Unicode/CRLF/首尾空白、撤销、修改顺序、过期输入与要求、重叠和未知编号、四类案例、已有输出目录保护，以及真实 HTTP 的来源和长度边界。

浏览器脚本在 1440 与 390 宽度检查逐条采纳与保留、撤销、保存重载、原稿变更、过期和无效建议导入、导出正文一致性、恶意 HTML 仅作文本、大纲导入及请求内容一致性。记录保存在 output/browser-check/acceptance.json，并由 CI 上传。指定 axe 规则通过也不代表完整无障碍认证。

[独立技能试跑](evaluation/skill-forward-test.md) 在新上下文处理不同的原创片段，实际校验零采纳和只采纳一项，其余原文逐字节保留。作者选择为预先声明的模拟输入，没有伪装成作者访谈或真实反馈。

## 未证明的能力

没有文学质量评分、真实作者效率提升、使用留存、安装到所有 AI 宿主的兼容性或生产多人协作结果。语义、原创性和风格边界由宿主及作者判断，JSON Schema 本身不作这些承诺。网页文本框遵循浏览器换行行为；需要精确保留 CRLF 文件时使用 CLI。

旧版验收见 [历史技术记录](technical-audit-2026-09-18.md)，不能用旧截图证明当前行为。复现入口为 README、docs/plugin.md、scripts/check_review.cjs 及 .github/workflows/quality.yml。

## 检查推动的修正

独立技能试跑发现链接的协议文档过旧、空问题标题和缺少单项采纳例子；已同步文档与渲染。浏览器测试先修正了测试工具自身的 CSP 注入方式和手机折叠菜单定位，再得到完整通过记录，没有放宽产品 CSP。视觉检查将空插图板改为按需展开，并让导入后的焦点和滚动定位到审阅起点。

Impeccable 检测器运行一次，缺少 HTML/CSS 解析模块，降级为正则检查。返回的设计令牌差异主要对应既有样式；没有把降级结果当作全量视觉检查通过。PRODUCT.md 和设计记录的既有格式未迁移，本轮仅补充实际新增交互。
